# v1.3.0 リリースノート

## 概要
- 対象: iRIC_DataScope
- リリース日: 2026/04/27
- 目的: 断面集計機能の追加、プロジェクト入力解決の改善、ユーザードキュメント整備

## ユーザ向けの主な変更
- 新機能として **断面集計** を追加しました。側線SHPに沿って平均水位・平均水深を断面別に集計し、CSV と断面グラフ PNG を出力できます。
- 断面集計で `section_node_map.csv`、`section_timeseries.csv`、`section_peak_summary.csv` の3種類のCSVを出力するようになりました。
- 断面ごとの **平均水位時系列グラフ** を PNG で出力するようになりました。最大点は値と時刻の注記付きで確認できます。
- 断面グラフの Y 軸は、既定で断面ごとの最適スケールを使い、必要に応じて全断面共通スケールへ切り替えられるようになりました。
- 断面集計の CSV 列名で `river` オプションを追加し、河川業務向けの日本語列名へ切り替えられるようになりました。
- 断面集計の入力として、ノード結果を前提に `watersurfaceelevation(m)` / `depth(m)` を集計対象にしました。

## 入力 / ランチャー改善
- `.ipro` / プロジェクトフォルダの解決を `project.xml` ベースへ見直し、基準CGNSと `Solution*.cgn` の解決を安定化しました。
- ランチャーおよび各機能の入力として `project.xml` を受け付けるようになりました。
- ランチャーで、存在しない出力フォルダを指定しても機能起動時に自動作成するようにしました。

## UI / ドキュメント
- 断面集計GUIを追加し、入力、集計設定、出力プレビュー、実行の流れで操作できるようにしました。
- 断面集計の完了ダイアログを整理し、CSV一覧とグラフ出力先のみを要約表示するようにしました。
- ユーザー向けドキュメントに **断面集計** ページを追加しました。
- ランチャー、左右岸水位抽出、横断重ね合わせ図作成、断面集計の画面キャプチャを更新し、画像ファイル名をバージョン番号付きで管理するようにしました。

## 影響範囲 / 互換性
- 主な影響機能: 断面集計、ランチャー入力判定、CGNS/ipro/project.xml 解決、ユーザードキュメント
- 互換性: 既存の `.ipro` / `.cgn` / プロジェクトフォルダ入力は継続利用可能です。
- 補足: 断面集計は側線SHPと計算結果が同一座標系である前提です。
